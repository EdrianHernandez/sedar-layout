# SEDAR Marketing Dashboard

Frontend prototype for SEDAR Marketing operations, including a responsive dashboard, collapsible navigation, customer directory, and customer relationship profiles.

## Technology

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:5173`.

## Validation

```bash
npm run lint
npm run typecheck
npm run build
```

## Prototype Scope

This repository is a frontend-only prototype. Customer and transaction records are fictional local mock data. It does not include authentication, API integration, database persistence, or backend services.
